# Changelog

## 0.1.0 — 2026-10-23

- Initial public release of Dandelion Drift for Linux.
- Endless side-scrolling flight with a 50-puff movement/health reserve.
- Flowers recharge the puff; every fourth released flap seed can plant a future flower.
- Bees, thistles, grass, ponds, frogs and gusts create pressure without additional game systems.
- Fireflies score chain points while draining 15 puffs on contact.
- Persistent local top-five scores with one-to-three-character initials.
- Full-screen 960×720 logical presentation with aspect-preserving scaling.
- Finished embedded artwork, fluid bunny presentation and procedural sound cues.
- Deterministic core tests, race testing, long-run hardening and Linux ARM64 build proof.
